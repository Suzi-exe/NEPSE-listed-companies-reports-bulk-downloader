# NEPSE-listed-companies-reports-bulk-downloader
This is a simple python script that would download NEPSE listed companies quartely report from merolagani website in bulk. 
To use this firstly you should have python installed. You should be ready with links of the finacial statement, you could do so by using simple chrome extension like LinkClump+ (You should proberly go to LinkClump+ setting to make so that while using it would only copy urls instead of opeing the urls and in advanced options "copy format" should be set to urls only) 
The urls that are copied should be then copied to links.txt (Initally example of CITY company is given)
Then you can run the .py file (Could be done so in IDLE Python)
When the images are downloaded you could convert them into one single pdf by using any online pdf generator
